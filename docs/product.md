# Product

> Make Pocket Brain a place where people can forget things safely, because
> their phone can help them find those things later.

Pocket Brain is a personal memory companion. It should feel calm and
personal, not like a complicated note-taking app.

## Problems it solves

1. *I found something useful.* — Save it before I forget.
2. *I remember reading something.* — Help me find it.
3. *I have too much information.* — Organise it for me.
4. *I don't remember the details.* — Explain what I saved.
5. *I need to act on something.* — Remind me at the right time.

## Principles

- **Local first.** Memories never leave the device; no account required.
- **AI suggests, the user decides.** Nothing AI-generated is saved without
  review, and original content is never rewritten.
- **Honest answers.** Ask Brain answers only from saved memories, shows its
  sources, and says when it can't find something.
- **Works without AI.** Every core flow works before any model is downloaded.

## Screens

| Screen | Purpose |
|---|---|
| Home | Greeting, Ask bar, digest, to-dos, collections, recent and resurfaced memories |
| Brain | Library: all, recently viewed, favourites, archived, categories, collections; list/grid |
| Capture | Note, link, clipboard → AI review → save |
| Ask Brain | Chat over memories with sources, follow-ups, regenerate, collection scope, history |
| Search | Smart (meaning) or exact search, filters, recent searches, hand-off to Ask |
| Memory details | Original content, AI summary, metadata, collection, tasks, related memories |
| Collection | Memories in a collection, search inside, ask about the collection |
| Daily digest | Today, topics this week, open tasks, on this day, worth revisiting, AI recap |
| Tasks & reminders | Overdue, upcoming, anytime, completed; linked back to memories |
| Settings | One "Pocket Brain AI" setup card (no model names), processing (CPU/GPU), storage, privacy, export, wipe |
